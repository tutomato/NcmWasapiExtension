# v0.7.0-preview.1

新增客户端内参数 EQ 入口：最多 10 段钟形、低音搁架和高音搁架，可调频率、增益和 Q，带总增益、保存、平直重置及峰值提示。默认关闭，仅对本扩展的 WASAPI 独占输出生效。请自行关闭网易云原有 EQ 和其他音效，避免叠加。

保留正常网易云启动方式、设备自动枚举和原采样率跟随。EQ 系数按实际流采样率计算，配置切换交叉淡化 20 ms。尚不包含 VST 宿主、动态 EQ、线性相位或自动更新。

继承安装向导 app 常量初始化错误修复。Windows x64 实验预发布，安装包未签名；兼容检测不等于所有客户端版本和设备已实测。

验证：133 项 Python 测试通过；原有 JavaScript 检查及新增 300 组滤波器系数检查通过。隔离进程运行真实 CModule，20 组采样率/声道/增益响应符合设定，左右隔离、缓冲边界、分块一致性及关闭旁路检查通过。真实浏览器面板输入、保存、无效输入拒绝、重置和清理通过。真实网易云副本用静音文件验证 Aurora 44.1/96 kHz 独占流的 EQ 处理帧数持续增长、配置读取和原采样率跟随；此项不等于 DAC 模拟输出频响测量。测试后移除副本加载器，客户端原厂文件哈希不变。
