# v0.6.0-preview.2 — 自动加载版（实验版）

在网易云音乐 Windows 客户端的输出设备列表中增加 **WASAPI（共享）** 和 **WASAPI（独占，自动采样率）**。安装后仍使用原来的网易云图标或 `cloudmusic.exe`，扩展随客户端自动加载，无需另开启动器。

## 本次修复

- 修复直接打开安装向导时报“安装目录尚未初始化”的错误。
- 将默认客户端查找与安装目录读取分开，并增加正常交互启动、中文路径、旧关联恢复及显式路径优先的回归检查。

## 安装与卸载

1. 完全退出网易云，包括通知区域中的网易云进程。
2. 下载 `windows-x64-setup.exe`，允许管理员安装，并确认网易云的 `cloudmusic.exe` 位置；无需另装 Python。
3. 安装完成后照常打开原网易云，在 **设置 → 播放 → 输出设备** 中选择设备及共享或独占模式。

更新或卸载前也请完全退出网易云。卸载通过 Windows“已安装的应用”中的“网易云输出扩展”完成；扩展配置和日志默认保留。

已有 BetterNCM 或其他来源的 `msimg32.dll` 时，安装器会提示冲突并停止，不会覆盖现有插件。发行版 `portable.zip` 供手动运行或部署工具使用，**仅解压不会安装自动加载功能**；普通用户请使用安装包。

## 兼容性与验证范围

- 支持 Windows 10 / 11 x64；按音频引擎、界面接口和自动加载入口的实际结构检测兼容性，不按产品版本号白名单启用。这不代表支持全部历史或未来版本。
- 真实客户端实测基线为网易云 **3.1.42.205594 x64**。独占输出优先跟随歌曲采样率；设备能力可能导致回退，不承诺逐位一致输出。
- 本轮在真实客户端独立副本中验证了同 PID 自动加载、客户端内新增输出选项、安全退出和移除；未进行本轮音频播放检查。此前 0.5 版完成的 Aurora 44.1 / 96 kHz 独占和采样率跟随检查单独记录。
- 129 项 Python 检查、69 项 JavaScript 模拟检查，以及原生加载、默认安装向导启动、安装、覆盖升级和卸载的隔离检查通过。其他真实客户端版本及全部硬件组合尚未实测。

此版本为 **Pre-release，安装包未作 Authenticode 签名**。下载后可使用同次发布的 `SHA256SUMS.txt` 核对文件；校验值不等同于发布者签名。
