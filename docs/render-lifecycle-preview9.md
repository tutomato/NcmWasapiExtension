# 音频对象归属清理

修复共享/独占切换时 COM 渲染对象地址复用导致旧独占记录误处理共享缓冲区的问题。GetService 成功时替换旧归属，共享对象移除旧映射；渲染接口释放时清理映射，处理缓冲区前验证所属客户端与代次。

故障日志记录了共享流初始化成功后紧接 ReleaseBuffer frame count 错误，随后扩展安全退出并启动普通客户端，独占选项因此消失。保留安全回退，修正触发它的陈旧映射。没有增加音频淡入。

验证：对象地址复用、GetService 失败不修改归属、代次失效、客户端退休、渲染对象释放与替换竞争的回归测试通过；137 项 Python 测试通过。实际网易云/Aurora 完成 8 次模式切换和 16 次切歌，未出现音频错误或普通模式回退，最终以 44.1 kHz/24 位独占输出。
