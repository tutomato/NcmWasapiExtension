# v0.7.0-preview.5 — 独占输出与原生参数 EQ 统一版本

一个“网易云输出扩展”安装包同时包含 WASAPI 共享 / 独占输出和参数 EQ。安装后仍从原网易云图标启动，共用原来的覆盖升级和卸载方式，无需另装 EQ 插件。

## 本次发布

- 保留设备自动识别、客户端内共享 / 独占选项及独占流优先跟随歌曲采样率输出。
- 参数 EQ 融入“播放栏 … → 音效 → 均衡器 → 参数 EQ”，沿用原窗口和皮肤，可切回标准均衡器。
- 支持最多 10 段钟形、低音搁架、高音搁架，提供频响预览和单频段编辑。
- Q 范围 0.2–20；频段增益 −18～+18 dB，总增益 −30～0 dB。范围直接显示，超界自动调整并提示。
- 新配置默认总增益、各频段增益均为 0 dB。修改后点击“应用并保存”才改变音频。
- 移除旧实验界面的悬浮入口、“恢复平直”和“预留增益空间”按钮。

## 安装、升级和卸载

下载本次 Assets 中的 windows-x64-setup.exe。完全退出网易云后运行，选择 cloudmusic.exe。从 0.6 系列直接覆盖升级即可，无需先卸载。

卸载仍在 Windows 的“已安装的应用”中选择“网易云输出扩展”，会同时移除独占输出与参数 EQ。个人设置和日志默认保留；网易云客户端、账户和音乐文件保留。

## 使用范围与验证

参数 EQ 仅在本扩展的 WASAPI 独占输出中生效。请关闭网易云原有 EQ 和其他音效，避免叠加。此版本没有 VST 宿主、动态 EQ 或线性相位模式。

本地通过 135 项 Python 测试、JavaScript 回归、360 组系数频响和 120 组 Q20 边界稳定性检查；真实原生 CModule 的 40 组采样率 / 声道 / Q / 增益响应通过。真实浏览器验证原生界面挂载、输入校正、零增益默认值及窗口恢复。统一安装包的首次安装、覆盖升级和卸载通过隔离客户端检查。真实网易云副本的 Aurora 44.1/96 kHz 静音流接入和处理帧数验证见此前记录，不等于 DAC 模拟输出频响测量。

Windows x64 实验预发布，客户端真实播放实测基线仍为 3.1.42.205594 x64；结构自适应检测不代表所有未来版本均已实测。安装包未作 Authenticode 签名，SHA256SUMS.txt 用于检测文件差异。
