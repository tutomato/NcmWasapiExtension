# v0.7.0-preview.2

参数 EQ 融入网易云原生“更多操作 → 音效 → 均衡器”页面，提供“标准均衡器 / 参数 EQ”切换。移除播放栏上方的悬浮按钮和独立浮层，沿用原音效窗口和皮肤。新增实际滤波系数计算的频响预览、10 个频段选择、单频段频率/增益/Q 编辑。原生音效总开关仍控制原生音效；参数 EQ 在自己的页面启用。

仍仅对本扩展的 WASAPI 独占输出生效。原有 EQ 和其他音效需自行关闭，避免叠加。音效子窗口通过受限、带确认回复的本机调试绑定连接，不能请求切换输出或调整音量。识别不到原生均衡器结构时不插入其他位置。

保留 0.7.0-preview.1 的音频处理，新增界面不改变滤波算法。子窗口关闭、重开或切回标准均衡器时移除自有节点并恢复原有内容。安装包未签名，实验预发布。

验证：134 项 Python 测试、现有 JavaScript 回归通过。真实浏览器原生结构夹具检查了参数保存、无效输入、原生控件恢复、关闭重开、窗口高度及主题颜色跟随。已在真实网易云的原生音效子窗口完成接入和视觉检查。音频 DSP 未更改，沿用上一版的原生频响与 Aurora 静音流验证。
