# v0.7.0-preview.3

参数 EQ 的 Q 值范围从 0.2–10 扩展为 0.2–20。10 是首版的保守产品边界，并非双二阶滤波算法的硬限制。新范围在界面中直接显示；超过上限时立即调整，低于下限在结束编辑时调整。空白恢复上一有效值，小数按控件精度校正，并显示具体提示。所有调整仍需点击应用才送到音频处理端。

频响预览在各频段中心及高 Q 的窄峰附近增加采样点，避免视觉上漏掉窄峰。增益为 0 dB 时，调整 Q 会提示频响不会改变。音频处理端仍独立拒绝范围外参数。

验证：134 项 Python 测试通过；360 组系数频响和 120 组 Q20 边界稳定性检查通过。真实原生 CModule 40 组采样率/声道/Q/增益响应及缓冲边界、声道隔离、分块一致性通过。真实浏览器检查 Q2/Q20 的曲线宽度、保存 Q20、上限自动调整、下限/空白/小数编辑完成后的校正。

保留原生音效窗口入口及 0.7.0-preview.2 布局。实验预发布，安装包未签名。
