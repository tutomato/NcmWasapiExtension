# 兼容性

## 当前支持范围

| 项目 | 范围 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11，x64 |
| 网易云音乐 | 内部结构检测通过的 **x64 客户端**；不按产品版本号或整包哈希白名单决定是否启用 |
| 自动加载入口 | 客户端具有可验证的 CEF 初始化导入及本地加载入口；目标位置没有其他来源的 `msimg32.dll` 冲突 |
| 真实播放实测基线 | **3.1.42.205594 x64**；当前没有对其他真实客户端版本完成播放回归 |
| 输出接口 | Windows WASAPI 共享 / 独占 |
| 设备 | 按当前活动输出端点及驱动报告的能力协商，支持默认设备选择 |
| 格式 | 在实现和驱动均支持时使用 PCM16、打包 PCM24、32 位容器中的 PCM24、PCM32 或 float32；声道按适配范围协商 |

Windows ARM64、32 位网易云以及未通过内部结构检测的客户端不在当前适配范围。多声道、DSD 直通、ASIO 和其他独立驱动接口不属于本版本承诺的功能。

不同设备对独占、采样率、位深、缓冲对齐和拔插恢复的要求可能不同。列出某种格式表示具备协商和转换实现，不等于每种硬件组合均已实测。设备即使报告格式可用，也可能在建立连接时因占用、系统策略或断开而失败。

## 采样率跟随

扩展优先将音频流与歌曲采样率匹配。设备能力限制或客户端处理链可能导致输出率不同；此时应以扩展显示的**源采样率和实际输出采样率**为准，而不是只看歌曲音质名称。

共享模式仍经过 Windows 音频引擎。独占模式也不等于网易云内部 DSP、音量和格式转换全部关闭。因此“源采样率一致”“独占连接成功”和“逐位无损”是不同的验证项目。

## 自动兼容检测

从 `0.5.0-preview.1` 起，用户不用选择对应网易云版本的插件包，也不要求降级客户端。扩展检查当前安装的实际代码结构和运行时接口；同一种音频架构中的位置、文件名或界面模块编号变化可以自动识别。

从 `0.6.0-preview.2` 起，安装版使用客户端目录中的本地加载组件，用户直接打开原网易云程序。没有开机常驻的进程监听器，不要求从另一个启动器进入。

检测分为以下几层：

- 离线检查 x64 PE 文件，在可执行段中寻找唯一的输出线程函数签名，核对 `.pdata` 函数边界及其与 `CreateThread` 导入的调用关系。函数位置通过扫描得到，不使用固定 RVA 作为回退。
- 按所需导出函数识别 FFmpeg 模块，并在进程中核对导出的归属、可执行地址及 ABI 主版本。当前理解的 ABI 为 **avcodec 58、avutil 56、swresample 3**；文件名变化不等于 ABI 变化。
- 在实际加载的 webpack 模块中按接口结构寻找音频桥接与音量模块，检查输出设备和音量的调用约定，不依赖固定模块编号。
- 在接管前重新核对运行时函数字节和模块信息；结构改变、缺少接口或结果不唯一时，不继续套用旧规则。
- 自动加载还检查 CEF 初始化入口的导入契约。安装目录已有 BetterNCM 或未知 `msimg32.dll` 时不覆盖；CEF 入口改变或不存在时不能按旧规则自动接入。

**自动检测不是对任意历史或未来客户端的兼容承诺。** 更换编译方式、重写音频线程、更换 FFmpeg ABI 或改变界面桥接协议，都可能需要更新适配规则。产品版本号相同也不能替代结构检查。

检测不通过时，扩展保持或恢复普通输出，并说明原因。继续使用普通网易云，更新扩展后重新检测；不要修改哈希、关闭结构校验或替换客户端 DLL 来强行启用。本项目不提供旧版网易云安装包，也不会自动降级或更新网易云。

原生加载组件只作用于所选网易云客户端。它为本次进程选择本机 loopback 临时调试端口，用于连接输出列表桥接；不设置全局系统启动拦截，不改变 Windows 安全功能。运行期间的辅助控制进程随本次网易云退出，不作为开机常驻服务。

自动加载前的只读运行时检查失败时，普通客户端继续启动。若已经开始安装音频转换钩子后才发生不兼容，扩展会先结束被适配的音频流，再尝试一次带旁路标记的普通启动；不会反复自动注入重启。用户正常退出、卸载或停止信号不会触发这次恢复启动。

## 已验证范围

目前真实客户端播放验证仍只有 `3.1.42.205594 x64`。新增检测已用重定位函数、改变相对地址、随机界面模块编号以及缺失、重复、损坏接口等模拟场景检查识别与拒绝行为。这些模拟结果证明检测不再依赖原来的固定位置和编号，不能代替其他真实客户端版本及硬件的播放回归。

`0.6.0-preview.2` 已在上述真实客户端的独立副本中验证：原 exe 启动后同一 PID 自动接入，客户端内共享及独占选项出现，安全停止和按归属移除加载文件通过。为保留用户正在运行的原客户端，测试仅临时隔离副本的单实例查找，隔离钩子随后完全移除；本轮未播放或切换音频。此前 Aurora 44.1 / 96 kHz 播放回归与本次自动加载检查分别记录。合成客户端还覆盖 CEF 初始化前的命令行接入和系统图形导出转发。

## 设备及失败后的恢复

- 默认设备选择会随 Windows 当前默认输出解析；固定设备选择绑定实际端点。
- 活动设备目录会定期刷新，拔插或默认设备变化后列表可能需要短暂更新时间。
- 独占设备被其他程序占用、驱动拒绝格式、设备断开等情况属于可恢复的输出错误，会显示提示。
- 客户端在一次输出失败后可能无法自行重新建立音频管线。重新选择或重播仍无声时，完全退出并重新打开网易云；不要把列表刷新当成已经恢复播放的证明。
- 转换或缓冲数据错误会触发受保护的退出流程。请先恢复普通输出，再提交问题。

## 发布前验证建议

维护者应在真实客户端上验证共享 / 独占切换、44.1 / 48 / 96 kHz 来源、设备不支持的采样率回退、暂停 / 继续、切歌、搜索拖动、默认设备变化、拔插、占用冲突以及扩展退出。合成数据检查和 CI 构建不能代替真实设备测试。
