# 切歌边界处理

修复新建或 Reset 后的音频流先从原始信号交叉渐变到 EQ 的问题。总增益和滤波参数从第一帧采用目标值；播放中调参仍保留 20 ms 交叉渐变。

独占流首次有效音频以及 Reset 后的有效音频添加 5 ms 平滑淡入，避免开始处直接从零跳到非零幅度。淡入与参数 EQ 开关无关；5 ms 后不修改采样。此处理只覆盖新流/Reset 的开头，不提供跨设备重锁或停止端淡出保证。

诊断：目标歌曲开头约 4 秒的峰值在 EQ 关闭/开启时分别约 0.769/0.767，无接口错误；之前累计 1.251 的峰值来自更长播放区间，不能作为开头炸音的证据。采样率切换与 DAC 重锁的可闻瞬态仍需听感确认。

更新后实际客户端重复切入《1993 (Remake)》：开头区间 EQ 0 dB 与 −3 dB 峰值分别为 0.567779/0.401957，较后区间为 0.732332/0.518451，比例均符合 −3 dB；各次接口错误数为 0。测试完成后恢复原有 EQ 参数。数字链路测试不能证明 DAC 模拟输出的可闻爆音完全消失。
