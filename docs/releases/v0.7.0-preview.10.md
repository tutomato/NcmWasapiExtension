# v0.7.0-preview.10 — 修复音质切换时的独占采样率跟随

播放中切换高清臻音、超清母带时，独占输出现按网易云当前音频处理链请求的采样率协商。此前扩展优先使用解码器采样率，导致处理后的 96 / 192 kHz 音频再次转换到 44.1 / 48 kHz，DAC 的读数因此保持原值。

## 本次修复

- 首次格式查询采用网易云实际请求的处理采样率，更新 GetMixFormat 阶段的临时选择。
- 保留独立的解码采样率与处理采样率记录，并按每个音频客户端分别协商，沿用设备能力限制及失败处理。
- 增加处理采样率、重复查询、普通来源、受限设备和共享输出的回归检查，已有音频对象生命周期测试在本地回归中通过。

## 自上次公开版本 preview.5 起的更新

- 参数 EQ 启用开关立即生效，增加一键重置与播放栏入口，并与标准均衡器互斥。
- 新建或 Reset 后的音频流从第一帧采用目标 EQ 参数。播放中调参沿用参数过渡，取消开头额外淡入。
- 修复共享 / 独占切换时复用渲染对象造成的旧归属残留，完善对象释放及代次检查。
- 更新使用说明和原生参数 EQ 截图。

## 验证范围

在 Windows x64、网易云 `3.1.42.205594 x64`、TOPPING USB DAC 上，直接在界面播放同一首在线歌曲《月半小夜曲》，播放中切档的 DAC 实测读数为高清臻音 96 → 超清母带 192 → 标准 44.1 → 高清臻音 96 kHz。正常启动已安装扩展后，臻音与母带的 96 / 192 kHz 切换复核通过，日志中的额外降采样消除。

这一验证覆盖输出采样率跟随。歌曲原始录音规格、所有客户端版本及硬件组合的兼容性仍需相应证据。

## 安装与文件

完全退出网易云，包括通知区域中的进程，下载本版本的 `windows-x64-setup.exe` 覆盖安装，然后照常从原网易云图标启动。在设置 → 播放 → 输出设备中选择对应 DAC 的“WASAPI（独占，自动采样率）”。个人 EQ 配置保留。

本次提供安装包、运行文件 ZIP、源码 ZIP 和 `SHA256SUMS.txt`。运行文件 ZIP 解压后供手动部署、调试使用，自动加载通过安装包安装。

本版本为 Windows x64 预发布，安装包未作 Authenticode 签名。SHA-256 校验用于核对下载文件。项目代码采用 MIT 许可，随包组件保留各自许可。
